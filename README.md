# CouchControl

**Английская версия: [CouchControl_en](https://github.com/kroshixxx-pixel/CouchControl_en).**

**Управление собственным Windows-ПК через личного Telegram-бота.**

CouchControl — небольшой Windows-агент и Telegram-бот с кнопочной панелью управления. Он позволяет выполнять повседневные действия на своём компьютере с телефона или другого устройства, где доступен Telegram.

> **Статус проекта:** проект находится в разработке. Перед использованием на основном компьютере проверьте установку и работу на тестовой системе. Описание функций ниже отражает текущую реализацию исходников, а не обещание абсолютной безопасности или безошибочной работы.

## Возможности

После запуска бота и команды `/start` появляется меню:

| Раздел | Что умеет |
|---|---|
| 🖱 Мышь | Перемещать курсор кнопками в восьми направлениях, нажимать левую и правую кнопки мыши, прокручивать колесо |
| ⌨️ Клавиатура | Отправлять текст для вставки в активное окно, нажимать Enter, Esc, Tab, стрелки, пробел, Backspace, Ctrl+C, Ctrl+V и Alt+Tab |
| 🔊 Громкость | Увеличивать и уменьшать громкость, включать/выключать звук |
| 🎵 Медиаплеер | Переключать воспроизведение/паузу, следующий и предыдущий трек |
| ⚡ Комбинации | Выполнять распространённые сочетания Windows: Alt+F4, Win+D, Win+I, Ctrl+Shift+Esc, Alt+Tab, Win+E и Win+R |
| 🗂 Приложения | Запускать поддерживаемые приложения из фиксированного списка: Блокнот, Калькулятор, Проводник и Paint |
| 📸 Медиа | Получать скриншот рабочего стола или запись экрана длительностью 15 секунд в виде MP4 |
| ⏻ Питание | Блокировать компьютер; выключать или перезагружать его после отдельного подтверждения. Команду выключения/перезагрузки можно отменить в течение 30 секунд |
| ℹ️ Статус | Получать ответ бота о том, что обработчик доступен |
| 🛑 Остановка | Останавливать самого бота. Это не выключает компьютер; для повторного запуска нужно открыть CouchControl на ПК |

Часть действий выполняется сразу после нажатия кнопки. Для потенциально disruptive-действий — выключения и перезагрузки — предусмотрено дополнительное подтверждение.

## Как это работает

1. На Windows-компьютере устанавливается и запускается CouchControl.
2. Агент запускает Telegram-бота и получает обновления через Telegram Bot API (long polling).
3. Пользователь нажимает кнопки в личном чате с ботом.
4. Бот проверяет Telegram User ID отправителя и то, что запрос пришёл из личного чата.
5. Если проверка пройдена, агент выполняет соответствующее локальное действие в Windows с правами текущего пользователя.
6. Ответы, скриншоты и видеозаписи отправляются обратно в Telegram.

Компьютер должен быть включён, пользовательская сессия Windows должна быть доступна для управления, а у ПК должен быть интернет. Бот не является облачным удалённым рабочим столом: основная программа работает именно на управляемом компьютере.

### Локальный веб-компонент

В проекте также есть локальный HTTP API для интерфейса Mini App. Он привязывается к `127.0.0.1`, а не ко всем сетевым интерфейсам. Запросы управления проверяют Origin и подпись Telegram Web App init data, а также разрешённый User ID. В текущем коде API предоставляет операции перемещения курсора и клика мышью. Не следует считать это доказательством безопасности всей системы или публичным удалённым сервером.

## Установка и запуск

Для текущего установочного проекта предусмотрен сценарий:

1. Запустить `CouchControl-Setup.exe`.
2. Ввести токен собственного Telegram-бота, созданного через [@BotFather](https://t.me/BotFather).
3. Ввести свой числовой Telegram User ID.
4. Дождаться подготовки отдельного Python runtime и установки зависимостей.
5. Запустить CouchControl и открыть личный чат с ботом, отправив `/start`.

Установщик проекта рассчитан на 64-битные Windows 10/11. Для загрузки Python и пакетов во время установки нужен интернет. Предусмотренные опции установщика позволяют создать ярлык и добавить запуск при входе в Windows.

**Важно:** установочный сценарий находится в разработке и требует проверки на чистой системе. Успешная компиляция Inno Setup сама по себе не означает, что установка и запуск уже протестированы.

## Безопасность и приватность

Безопасность важна, потому что CouchControl не просто отправляет сообщения: он может управлять мышью, клавиатурой и питанием компьютера.

### Что предусмотрено в коде

- **Ограничение по Telegram User ID.** Команды принимаются только от указанного в настройках пользователя и только в личном чате с ботом.
- **Нет произвольного выполнения команд из чата.** Запуск приложений реализован через фиксированный список программ; для них используется запуск без shell.
- **Подтверждение питания.** Выключение и перезагрузка требуют второго нажатия; команда планируется на 30 секунд и может быть отменена.
- **Локальный API не слушает внешние интерфейсы.** Веб-компонент привязан к `127.0.0.1`.
- **Проверка Telegram Mini App.** Для API управления мышью проверяются Origin, криптографическая подпись init data и ID пользователя.
- **Аварийная остановка PyAutoGUI.** Включён стандартный failsafe PyAutoGUI.

### Что важно понимать

- **Токен бота — секретный ключ.** Он хранится в локальном файле `.env` в виде обычного текста. Не публикуйте этот файл, не добавляйте его в Git и не отправляйте другим людям. В репозитории должен находиться только шаблон `.env.example`, без реального токена.
- **Telegram User ID не заменяет токен.** ID ограничивает, кто может пользоваться командами, но не защищает от последствий кражи токена. Если токен утёк, отзовите его через @BotFather и создайте новый.
- **Управление ПК имеет реальные последствия.** Нажатия клавиш и мыши выполняются в активной сессии Windows. Не оставляйте доступ к своему Telegram-аккаунту и устройству без защиты.
- **Скриншоты и видео раскрывают содержимое экрана.** Они отправляются через Telegram и могут содержать личные сообщения, документы, уведомления и другие приватные данные. Делайте захват только когда понимаете, что попадёт в кадр.
- **Логи могут содержать технические сведения.** Перед публикацией диагностических журналов проверьте их и удалите токены, личные данные и другие секреты, если они туда попали.
- **Зависимости загружаются из внешних источников.** Как и любое Python-приложение с пакетами, проект зависит от безопасности Python, библиотек и каналов их распространения.
- **Это не аудит безопасности.** В проекте нет независимого аудита, формальной модели угроз или гарантии защиты от вредоносного ПО на компьютере, компрометации Telegram, уязвимостей зависимостей и ошибок конфигурации.

### Рекомендации

1. Создайте отдельного бота только для CouchControl.
2. Храните токен в `.env` и никогда не публикуйте его.
3. Включите двухэтапную аутентификацию Telegram и защиту блокировки устройства.
4. Не используйте CouchControl на чужом компьютере без явного разрешения владельца.
5. Сначала проверьте функции на тестовом ПК и не оставляйте компьютер без присмотра во время первых запусков.
6. Если токен оказался в публичном месте, немедленно отзовите его у @BotFather.

## Требования

- Windows 10 или Windows 11, 64-bit.
- Интернет на компьютере.
- Собственный Telegram-бот и его токен.
- Числовой Telegram User ID владельца.
- Активная пользовательская сессия Windows для управления рабочим столом.

## Диагностика

Если установка завершилась ошибкой, проверьте журналы в папке временных файлов Windows:

- `%TEMP%\CouchControl-install-diagnostic.log`
- `%TEMP%\CouchControl-Python-install.log`

Не публикуйте журналы до проверки на секреты и персональные данные.

## Разработка

Основные файлы установочного проекта находятся в `setup/CouchControl/`:

- `bot.py` — Telegram-бот и обработчики кнопок.
- `web_server.py` — локальный API для Mini App.
- `requirements.txt` — Python-зависимости.
- `install.ps1` — подготовка Python-окружения и установка зависимостей.
- `CouchControl.iss` — сценарий Inno Setup.

Вопросы, предложения и сообщения об ошибках можно оформлять через Issues репозитория.
